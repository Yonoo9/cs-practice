git diff показывает различия между двумя состояниями файлов. Можно сравнить коммиты, рабочую папку и индекс.

git show показывает информацию об одном конкретном объекте, например о коммите.

git log показывает историю коммитов.



git log -S"def" команда ищет коммиты, в которых изменилось количество точных вхождений строки def.

git blame lab03/calc.py команда показывает, какой коммит последним изменил каждую строку файла. По результатам команды можно определить, кто и в каком коммите изменял отдельные строки файла.



git restore восстанавливает файл в рабочей папке из индекса.

git restore --source=... восстанавливает файл из указанного источника.

Если выполнить git restore, незакоммиченные изменения файла будут заменены версией из индекса.

Если выполнить git restore --source=HEAD\~1, файл будет заменён версией из предыдущего коммита.
