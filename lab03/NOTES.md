it diff показывает различия между двумя состояниями файлов. Можно сравнить коммиты, рабочую папку и индекс.

git show показывает информацию об одном конкретном объекте, например о коммите.

git log показывает историю коммитов.

git log -S"def" команда ищет коммиты, в которых изменилось количество точных вхождений строки def.

git blame команда показывает, какой коммит последним изменил каждую строку файла. По результатам команды можно определить, кто и в каком коммите изменял отдельные строки файла.

git restore восстанавливает файл из индекса
git restore --source=... восстанавливает файл из определенного коммита

git reset --hard перемещает текущую ветку на указанный коммит, сбрасывает индекс и рабочую директорию к его состоянию.

В опубликованной истории другие участники могут уже использовать существующие коммиты. git revert не переписывает историю, а добавляет новый коммит с обратными изменениями.
