Рабочая папка - файлы которые я редактирую
Индекс - подготовленные файлы для коммита
Коммит - сохраненный в репозиторий индекс
Git - система контроля версий
Github - сайт
Использованные команды:
git status - показывает состояние репозитория
git diff - показывает разницу между файлами в рабочей папке и в индексе
git diff --staged - показывает разницу между файлами в индексе и коммите
